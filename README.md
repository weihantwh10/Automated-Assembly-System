# 🤖 Mechatronics Assembly System

An automated mechatronics-based system designed to assemble two rectangular components using screws and nuts without human intervention.

---

## 📌 Project Overview

This project focuses on automating repetitive assembly tasks commonly found in manufacturing environments. The system reduces manual effort by using a combination of mechanical fixtures, pneumatic actuation, and microcontroller-based control.

The operator only needs to load components and start the system. The rest of the process is fully automated.

---

## 🎯 Objective

To develop an efficient, low-cost automated assembly system that reduces repetitive manual labor in manufacturing processes.

---

## ⚙️ System Features

- Fully automated assembly process
- Jig and fixture-based alignment
- Pneumatic-assisted fastening
- Servo and stepper motor actuation
- Compact and modular design

---

## 🧩 Product Components

- Top piece  
- Bottom piece  
- 2 Screws  
- 2 Nuts  

---

## 🔧 Assembly Process

1. Align top and bottom components  
2. Insert nuts into bottom slots  
3. Insert screws into top holes  
4. Tighten screws using automated mechanism  

---

## 📏 Specifications

- **Dimensions:** 500mm × 500mm × 351.8mm  
- **Power Supply:** 12V 5A, 9V, 5V  
- **Microcontroller:** Arduino Mega  
- **Air Pressure:** 4 bar  
- **Cycle Time:** ~50 seconds per assembly  

---

## ⚡ Power System

- **12V:** Stepper motors, solenoid valves  
- **9V:** Arduino Mega  
- **5V:** Servo motors, sensors, limit switches  

---

## 🧠 Control System

The system is controlled using an **Arduino Mega**, chosen for its high number of GPIO pins required to manage multiple actuators and sensors.

---

## 🏗️ Mechanical Design

- Aluminium profile frame  
- Mostly 3D-printed parts  
- Compact structure  
- Precision alignment using jigs and fixtures  

---

## 💨 Pneumatic System

- Operating pressure: 4 bar  
- Used for controlled fastening operations  
- Ensures smooth and stable movement  

---

## 🚀 Performance

- Fully automated assembly cycle  
- ~1 part per minute throughput  
- Designed for scalability in mass production environments
